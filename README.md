# Llama Chatbot App
– Developing a chatbot application powered by the open-source Llama LLM to provide automated feedback on
compiler course assignments
– Implementing core model logic in Python using PyTorch, NumPy, and Google Colab, focusing on analyzing
code submissions involving grammars, tokens, languages, and translators
– Deploying the Llama model on Microsoft Azure for scalable cloud processing, while designing a TypeScript
and React frontend and a FastAPI backend for seamless integration
– Integrating a PostgreSQL database to manage user interactions, feedback logs, and assignment data for
persistent storage and analysis
