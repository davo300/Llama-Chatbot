# Llama 4 Chatbot App
– Developing a chatbot application powered by the open-source Llama 4 LLM to provide automated feedback on
compiler course assignments
– Implementing core model logic in Python using PyTorch, NumPy, and Google Colab, focusing on analyzing
code submissions involving grammars, tokens, languages, and translators
– Planning to configure the Llama 4 model on cloud services (e.g., AWS) for scalable deployment, while designing a
TypeScript and React frontend and a FastAPI backend for seamless integration
